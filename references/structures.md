# 三种结构模式的完整示例

照着改名字就能用。所有例子都遵守：一个大文件夹、里面一层子夹、子夹内再嵌套；只移动 / 改名 / 新建；每个大文件夹根目录一个 README.md。

## 模式 A：按项目（agent 产出、代码、多个独立事情）

```
agent/
├── README.md
├── daily-report/            ← 常驻服务，路径写死，不动
├── stock-tool/              ← 同上；桌面散落的相关资料收进 stock-tool/资料/
├── Our/                     ← 从别处整个搬入的 git 仓库
├── kling-duel/
│   ├── 原图/                 ← 桌面上属于它的两张图
│   └── codex/2026-07-07-ke-y/   ← 别处（Codex 工作区）属于它的会话夹，名字带来源+日期
├── ymppt/
├── youtube_faceless_channel/    ← 别处发现的、自成一体的项目，升为顶层项目
└── 小任务/                   ← 零散产出兜底
    ├── 网速测试/
    ├── 十问H5-love-survey/
    │   ├── 问卷星导出/
    │   └── codex-2026-07-14-bang-问卷网站/
    ├── 考研计划/
    ├── ym.html
    └── wenda-MOVED.md
```

要点：
- "同类项合并、以基准位置为准"：别处出现的同一个项目的东西，往基准位置的那个项目夹里并，不反过来。
- 会话夹 / 报告夹整夹搬入，名字带来源和日期。
- 项目内部的散件用小夹（`资料/`、`原图/`、`旧版（来自下载）/`）收，不要平铺在项目根。

## 模式 B：按流程阶段（论文、申报、一件事的全过程）

```
毕业论文/
├── README.md
├── 01-选题与开题/            ← 桌面 开题报告/ 整个改名搬入 + 归档资料里的选题表、评阅意见 + 下载夹的开题答辩 PPT
├── 02-论文初稿与修改稿/       ← 桌面 毕业设计/ 整个改名搬入 + 散件；4月早期版本/ 放下载夹里更早的六份
├── 03-查重与AIGC检测报告/     ← 数字编号夹改成 2026-06-08_查重报告全套/ 等；散件副本/
├── 04-答辩/                  ← iCloud副本/ 放云盘那份同名 PPT
├── 05-终稿/                  ← 学校提交包目录原样保留在里面
├── 06-论文插图/
├── 07-Verilog代码与仿真/      ← ModelSim版本（来自下载）/ 放另一套同名 .v
├── 08-过程管理与毕业手续/     ← 过程管理手册、学院通知（URL 编码名已解码）、录用通知单
├── 09-模板与同学参考材料/
└── 10-工具安装包/            ← 用户要求收进来的 dmg 和软件目录
```

要点：
- 两位数字前缀 = 流程顺序；后来发现要插一个阶段（答辩）就整体重编号——文件夹刚建、成本很低，比乱序好。重编号时注意顺序避免撞名（先把大号往后挪）。
- 同名撞车放阶段内的子夹（`iCloud副本/`、`散件副本/`、`其他版本（来自下载）/`），并在 README 里注明大小 / 日期是否相同。
- 属于另一件事的材料（例：别人的论文文献）按用户选择不收，写进 README 的"没收进来的"。

## 模式 C：按文件类型（无处可归的散件；区分度故意不高）

```
零散文件/
├── README.md
├── 截图/            Mac 截屏 + 手机截屏 + 微信里转出来的截图
├── 图片/            照片、生成图
├── 视频/            散的 mp4（没有就留空夹）
├── 文档/            pdf/doc/docx/pptx/xlsx/md/epub…
│   ├── 课程资料/     ← 只在"一眼能看出的组"再分一层
│   ├── 准考证/
│   ├── 考研资料/
│   └── 重复副本/
├── 安装包与压缩包/   dmg / zip / apk / rar / .app 安装器
└── 其他/            看不出类型的（.ms14、0 字节的怪文件、空文件夹）
```

要点：
- 云盘里的散件"就地"整理时，在云盘根目录建同名的 `零散文件/`，结构一样。
- 已经是文件夹的东西（`小说/`、`考研数学/`、`clanguage/`）默认不动，汇报里问一句要不要也收。
- 视频 / 图片这类大文件在同一卷内 `mv` 是瞬间的，不用担心大小；跨卷（外接盘 → 本机）才是真拷贝，要先说。

## README 模板

```markdown
# <大文件夹名>

<日期> 从 <哪几个位置> 归拢到这里，按 <项目 / 流程 / 类型> 分子文件夹。只做了移动、改名和新建，没有删除任何文件；同名撞车的放 `重复副本/`。

| 子文件夹 | 里面是什么 | 原来在哪 |
|---|---|---|
| `01-…/` | … | 桌面 `xxx/`（整个改名搬入）+ 下载夹 |
| … | … | … |

## 备注 / 没收进来的
- `xxx/~$yyy.docx` 是 Word 临时锁文件，没用，我没删，你可以自己删。
- <按用户选择没收的东西>
- <需要用户手动做的：例如 `ln -s ~/Desktop/agent/glm-coding-rush ~/glm-coding-rush`>
- <没权限查看的位置：/Volumes 外接盘>
```
